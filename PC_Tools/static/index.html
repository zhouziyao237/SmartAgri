RADIO & DEPLOYMENT

无线与节点部署

V2.4.8 支持 ESP-NOW 真广播发现、自动绑定、跨 Channel 扫描与远程 Radio Config；AT 只保留为维护后门。

ESP Radio Config

远程配置直接送到目标 ESP。旧 V2.4.2-V2.4.6 节点仍保持 Protocol-2 基础通信，但可能不支持此管理命令。

新 SLAVE 不需要先配置 Gateway MAC：未绑定时会用 FF:FF:FF:FF:FF:FF 广播 LINK_HELLO，并在启用 Channel Scan 时轮询 1–13；收到新/旧 Protocol-2 MASTER 的 LINK_ACK 后自动保存 MASTER MAC 与实际 Channel。

版本与能力

Firmware 与 Protocol 分离；有 Protocol 2 交集即可基础通信，新功能按 capability 降级。

REMOTE FIRMWARE

Node 远程 OTA

同一 Node 可分别升级 STM32 与 ESP。升级任务按组件独立管理并显示进度。

创建 OTA 任务

先读取目标信息，再上传与目标组件匹配的 .bin。

使用顺序： ① Node/组件 → ② 读取目标信息 → ③ 选择匹配的 .bin → ④ 开始 OTA → ⑤ 等待 100% DONE。
STM32 首次启用 OTA 必须先通过 ST-LINK 安装 V2.4 Bootloader + V2.4 App；ESP 首次需要先有 V2.4 OTA 固件。
STM32：选择 relocated smart_agri_comm.bin，不要选择 bootloader / ELF / HEX。

目标组件信息

目标类型与最大镜像大小由设备返回。
